# VR-тренажёр

Тестовое задание Junior VR Unity Developer: короткий VR-сценарий с захватом предмета, установкой в сокет и включением рычага. Проект рассчитан на **Unity 6000.0.58f2 (Unity 6)**, **URP** и **XR Interaction Toolkit 3.x** (в проекте установлен XRI 3.0.11).

## Как открыть и запустить

1. Откройте корень проекта в Unity Hub с версией редактора **6000.0.58f2**.
2. В Unity откройте `Assets/Scenes/TrainerScene.unity`. Сцена настраивается вручную в редакторе.
3. Для перезапуска по `R` добавьте `TrainerScene` в **File → Build Profiles → Scene List** (можно кнопкой **Add Open Scenes**). Сейчас в списке сцен проекта находится только `SampleScene`, поэтому без этого шага `LoadScene` не сможет перезагрузить тренировку.
4. Проверьте ссылки в `ScenarioController` на объекте `GameController` и значение **Text Finished**: `Тренировка завершена. Нажмите R для перезапуска.` В текущей сцене в Inspector сохранён старый текст. Скрипт допишет подсказку при запуске, но для совпадения с новым значением по умолчанию обновите поле в Inspector вручную.
5. Нажмите **Play**. Текст задания виден на `TaskCanvas` перед камерой. После завершения нажмите `R` в активной вкладке **Game** для перезапуска.

### Прогон без VR-шлема

Используются официальные **Samples** пакета XR Interaction Toolkit: **Starter Assets** (настройки XR Origin и Input Actions) и **XR Device Simulator**. Если они ещё не импортированы, откройте **Window → Package Manager → XR Interaction Toolkit → Samples** и импортируйте оба образца. Добавьте в сцену префаб `Assets/Samples/XR Interaction Toolkit/3.0.11/XR Device Simulator/XR Device Simulator.prefab` (или используйте **GameObject → XR → XR Device Simulator**, если этот пункт доступен). В текущей `TrainerScene` симулятор уже добавлен: второй экземпляр не нужен.

Во время **Play** кликните по вкладке **Game**, чтобы она принимала клавиши. Основные привязки установленного образца:

| Действие | Клавиши/мышь |
| --- | --- |
| Выбрать устройство (голова, левый/правый контроллер) | `Tab` |
| Временно управлять левым/правым контроллером | удерживать `Left Shift` / `Space` |
| Переместить выбранное устройство | `W/A/S/D`, вверх/вниз — `E/Q` |
| Повернуть/переместить голову мышью | удерживать правую кнопку мыши и двигать мышь |
| Захватить или отпустить предмет контроллером | удерживать `G` (Grip) для захвата, отпустить для сброса; в Starter Assets действие Select привязано к Grip |
| Нажать триггер контроллера | левая кнопка мыши |

Подведите контроллер к `ObjectA`, удерживайте `G`, перенесите предмет к `SocketPoint` и отпустите `G`. Затем захватите `LeverHandle` и переместите контроллер, чтобы поднять рычаг. Панель симулятора в Game View показывает активное устройство и дополнительные клавиши. В образце симулятора `R` также переключает режим движения мыши; перезапуск сценария по `R` работает **только после финального шага**.

## Сценарий

| Шаг | Действие | Текст на панели |
| --- | --- | --- |
| 1 | Взять `ObjectA` со стола | «Возьмите объект A со стола.» |
| 2 | Установить `ObjectA` в `SocketPoint` на `ObjectB` | «Подойдите к объекту B и установите в него объект A.» |
| 3 | Перевести рычаг в положение «Включено» | «Подойдите к рычагу и переведите его в положение «Включено».» |
| Финал | Все действия выполнены | «Тренировка завершена. Нажмите R для перезапуска.» |

Подсветка указывает на объект текущего шага. До шага установки сокет выключен; до шага рычага выключен `LeverInteractable`. Повторные и преждевременные события не продвигают сценарий.

## Архитектура

| Файл | Ответственность |
| --- | --- |
| `Assets/Scripts/Trainer/TrainerStep.cs` | Перечисление четырёх состояний сценария. |
| `Assets/Scripts/Trainer/HighlightController.cs` | Пульсирующая подсветка через emission экземпляров материалов URP. |
| `Assets/Scripts/Trainer/TaskUIView.cs` | Вывод текста задания на TMP-панель. |
| `Assets/Scripts/Trainer/LeverInteractable.cs` | XR-взаимодействие с рычагом, вращение без физики и событие включения. |
| `Assets/Scripts/Trainer/ScenarioController.cs` | Строгая последовательность, доступность сокета и рычага, подсветка, текст и перезапуск. |

## Проверка негативных сценариев

1. Запустите сцену заново. До захвата `ObjectA` попробуйте взаимодействовать с рычагом и поместить предмет в `SocketPoint`: шаг остаётся первым, текст не меняется, сокет и рычаг выключены.
2. Возьмите `ObjectA`. Должен включиться только сокет и появиться текст второго шага. Попробуйте поднять рычаг до установки предмета: третий шаг не наступает.
3. На втором шаге попробуйте поместить в сокет другой XR-предмет, если он есть в сцене: событие чужого предмета игнорируется, шаг не меняется. Затем поместите именно `ObjectA`.
4. После перехода к рычагу повторно захватите `ObjectA` или вызовите событие сокета: сценарий остаётся на третьем шаге. Поднимите рычаг до включения; появится финальный текст и погаснет подсветка.
5. Нажмите `R` до финала: сценарий не перезапускается. После финала нажмите `R`: сцена загружается заново с первым заданием.

## Инструкция для редактора

| Объект сцены | Компоненты и ссылки |
| --- | --- |
| `ObjectA` | Коллайдер, `Rigidbody` (`Is Kinematic` включён, `Use Gravity` выключен), `XR Grab Interactable`, `HighlightController`. |
| `ObjectB` → `SocketPoint` | На `ObjectB` — `HighlightController`; на `SocketPoint` — `Sphere Collider` (`Is Trigger`, радиус около `0.2`) и `XR Socket Interactor`. |
| `LeverBase` → `LeverPivot` → `LeverHandle` | На `LeverPivot` — `LeverInteractable`; на `LeverHandle` — коллайдер для наведения и захвата. `HighlightController` разместите на объекте рычага, содержащем визуальный MeshRenderer в себе или дочерних объектах. |
| `XR Origin` → `Main Camera` → `TaskCanvas` → `TaskText` | `TaskCanvas`: `Canvas` в режиме `World Space`, локальная позиция `(0, -0.35, 0.9)`, масштаб `(0.001, 0.001, 0.001)`, `TaskUIView`; `TaskText`: `TextMeshProUGUI`. В `TaskUIView.Text` перетащите `TaskText`. |
| `GameController` | `ScenarioController`: `Object A` → `ObjectA` (`XR Grab Interactable`), `Socket` → `SocketPoint`, `Lever` → `LeverPivot`, три `Highlight` → соответственно `ObjectA`, `ObjectB` и рычаг, `Ui` → `TaskCanvas` (`TaskUIView`). Проверьте четыре текстовых поля, особенно **Text Finished**. |

`GameController` — пустой объект в корне Hierarchy. Если его нет, создайте через **GameObject → Create Empty**, назовите `GameController` и добавьте `ScenarioController` через **Add Component**.
